# Runbook diagrams

These self-contained SVG images use generic labels only:

- `connection-layout.svg`: browser, Relay backend, Soju, and upstream IRC.
- `migration-workflow.svg`: staged migration and verification.

Edit the SVG source directly. No external fonts, scripts, or network resources are required. Keep the SVG title, description, and document alt text consistent when changing a diagram.

Preview both images before publishing, including at a narrow width. The accompanying runbook text is the authoritative step-by-step procedure; the images are summaries.
